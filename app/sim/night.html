The cost tier

Measures how many taps it costs to get an answer onto a screen, for the same 60 questions the availability tier answers over HTTP. It opens its own table, seats one DM and five players, and drives them one at a time — every frame on this origin shares a token slot, so simultaneous seats are not possible and a turn order is sequential anyway.

Keep this tab in front. A backgrounded tab clamps timers to about a second, which does not corrupt anything but makes a run take roughly sixteen times as long.
